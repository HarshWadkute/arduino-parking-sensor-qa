# arduino-parking-sensor-qa

Project Timeline

The project is planned over four weeks, covering initial setup, quality assurance testing, bug fixes, and final reporting.

Week	Phase	Planned Activities	Deliverables
Week 1	Setup	Configure the repository, prepare the Arduino sketch, document circuit connections, and capture the circuit screenshot.	Initial implementation and circuit documentation
Week 2	QA Testing	Test distance readings, buzzer activation, sensor timeout behaviour, and invalid readings. Record confirmed defects as GitHub Issues.	Test plan and bug reports
Week 3	Fixes	Fix confirmed bugs, implement improvements, and verify fixes using the test plan.	Updated code and reviewed pull requests
Week 4	Final Report	Perform regression testing, update documentation, review outstanding issues, and prepare the final QA report.	Verified implementation and final QA report

Planned Releases

* v0.1 Initial code: Basic Arduino parking sensor implementation.
* v0.2 QA fixes: Tested and improved implementation with documented bug fixes.
* v1.0 Final: Verified implementation with completed documentation and QA report.

Progress will be tracked using GitHub Projects, Issues, Labels, and Milestones.
